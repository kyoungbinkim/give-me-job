## Evidence Strength

- `High`: concrete role, problem, action, result, and metric are present.
- `Medium`: concrete action and result are present, but metric or scope is weak.
- `Low`: mostly attitude, intent, or generic description. Ask follow-up questions before using it as a core cover letter claim.

## ID Rules

- Use stable IDs such as `EXP-001`.
- Do not reuse IDs for different experiences.
- Cover letters and evidence maps should reference these IDs.
