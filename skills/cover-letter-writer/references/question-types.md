# Cover Letter Question Types

| Type | Evaluation Intent | Resume Evidence |
| --- | --- | --- |
| 지원동기 | company understanding, role motivation, career direction | Target Roles, Career Vision, related experience |
| 직무수행 경험 | job capability, similar work, repeatable result | Experience Bank, Work History, Metrics |
| 성장과정/성격 | values, behavior pattern, culture fit | behavior examples, feedback, repeated choices |
| 협업/소통 | shared goal, conflict resolution, coordination | collaboration, conflict, action/result |
| 문제해결 | problem definition, execution, improvement | Problem, Action, Result, prevention |
| 창의/도전 | initiative, experiment, risk handling | improvement, trial, failure learning |
| 직업윤리/가치관 | responsibility, trust, judgment | principle-based decisions, difficult choices |
| 입사 후 포부 | growth plan, future contribution | Career Vision, 1-Year Contribution, 3-Year Growth Direction |

Use the table to choose structure, not to force keywords into the answer.
