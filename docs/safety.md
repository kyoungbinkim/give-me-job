# Safety Policy

`give-me-job` prepares application materials. It is not an automatic submission bot.

## Allowed

- Create or improve `resume.md` from user-provided facts.
- Analyze JD text or a hiring-post URL.
- Analyze optional company values or culture text.
- Draft Korean cover-letter answers grounded in `resume.md`.
- Produce an evidence map for strong claims.
- Run HR review before final text.
- Create a company-specific package and manual submission checklist.

## Not Allowed

- Invent experience, metrics, responsibilities, awards, tools, or company names.
- Copy company values text verbatim into cover letters.
- Create final text when HR blockers remain unresolved.
- Click final submit or send buttons.
- Bypass CAPTCHA, login, payment, consent, or access-control prompts.
- Transmit personal information without explicit user action.
- Mark an application as submitted unless the user says they submitted it.

## Blocker Examples

- A final answer claims a metric that does not exist in `resume.md`.
- A cover letter contains another company name.
- A JD requires a qualification that the candidate cannot support.
- The next requested action would submit the application.

When a blocker appears, stop and ask the user for missing evidence, a correction, or explicit risk acceptance.
