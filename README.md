# give-me-job

AI 기반 취업 도우미 에이전트 개발 프로젝트입니다.

## 목표

신입과 경력 지원자를 구분해 이력서 소스 정리, JD 분석, 기업 인재상 매칭, 자기소개서 작성, HR 관점 리뷰를 지원합니다.

## MVP 범위

- `resume.md` 기반 경험 은행 구축
- 신입/경력 분기형 입력 질문
- 채용 공고와 JD 핵심 역량 분석
- 기업 인재상/핵심가치 분석
- 자기소개서 초안 작성
- HR 관점의 제출 전 리뷰

## 초기 문서

- `job-agent-plan.md`: 전체 개발 계획과 트레이드오프

## 원칙

- 사용자가 제공하지 않은 경력이나 성과를 만들지 않습니다.
- 기업 인재상 문구를 그대로 복사하지 않습니다.
- 모든 강한 주장에는 실제 경험 근거를 연결합니다.
- 자동 제출이 아니라 작성 보조와 검토에 집중합니다.
